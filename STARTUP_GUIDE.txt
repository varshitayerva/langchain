                     MARGINGUARD - STARTUP GUIDE

👋 WELCOME! Follow these steps to run MarginGuard locally.

═══════════════════════════════════════════════════════════════════════════════
STEP 1: OPEN TWO TERMINALS
═══════════════════════════════════════════════════════════════════════════════

Terminal 1 (for Backend)  ← Keep this running
Terminal 2 (for Frontend) ← Keep this running

═══════════════════════════════════════════════════════════════════════════════
STEP 2: TERMINAL 1 - START BACKEND API
═══════════════════════════════════════════════════════════════════════════════

Copy & Paste These Commands:

📍 Windows PowerShell or CMD:
───────────────────────────────────────────────────────────────────────────────
cd c:\Users\samriddhi.mishra\langchain\reviewer\langchain
pip install -r api/requirements.txt
python -m uvicorn api.hitl_api:app --reload --host 0.0.0.0 --port 8000
───────────────────────────────────────────────────────────────────────────────

📍 macOS/Linux Bash:
───────────────────────────────────────────────────────────────────────────────
cd ~/path/to/langchain/reviewer/langchain
pip install -r api/requirements.txt
python -m uvicorn api.hitl_api:app --reload --host 0.0.0.0 --port 8000
───────────────────────────────────────────────────────────────────────────────

✅ Wait for this message:
   "Uvicorn running on http://0.0.0.0:8000"
   "Application startup complete"

🔗 Backend is ready at: http://localhost:8000

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

❌ Backend won't start:
   → Try: python -m uvicorn api.hitl_api:app --port 8001 (different port)
   → Check: pip install -r api/requirements.txt

❌ Frontend won't start:
   → Try: npm install (full reinstall)
   → Clear cache: npm cache clean --force

❌ Can't connect frontend to backend:
   → Make sure both are running (check both terminals)
   → Check ports: Backend=8000, Frontend=3000
